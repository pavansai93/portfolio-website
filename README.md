# Pavan Sai - Portfolio Website

This is the repository for my personal portfolio website, showcasing my experience as a Software Development Engineer specializing in distributed systems, Java backend microservices, and high-throughput data processing.

## 🚀 Technologies Used
- **React** (v18)
- **Vite** (v5)
- **Vanilla CSS**
- **Lucide React** (Icons)

## 📦 Running Locally
To run this project on your local machine:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.

## 🛠️ Building for Production
To build the static files for production deployment:
```bash
npm run build
```
The output will be available in the `dist` directory.
